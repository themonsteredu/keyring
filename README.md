# 스마트 감정·날씨 키링

ESP32-C3 SuperMini와 128×64 OLED로 만드는 초등학생용 키링입니다. 스마트폰에서 캐릭터와 감정을 고르면 OLED에 같은 픽셀 그림이 나오고, 저장한 설정은 USB 전원을 다시 연결해도 유지됩니다. 날씨는 스마트폰으로 받아 기기에 보관합니다.

## 준비물과 고정 배선

현재 필요한 부품은 ESP32-C3 SuperMini, 0.96인치 I2C SSD1306 OLED, 암암 점퍼선 4개, 데이터 전송이 되는 USB-C 케이블입니다. 전원은 USB를 사용합니다. 배터리·충전 회로·추가 버튼은 가정하지 않습니다.

| OLED | ESP32-C3 SuperMini |
| --- | --- |
| GND | G |
| VCC | 3.3V |
| SDA | GPIO4 |
| SCL | GPIO5 |

**SDA는 GPIO4, SCL은 GPIO5로 고정합니다.** 이 배선은 기존 `OLED OK` 테스트에서 동작한 배선입니다. USB 전원을 분리한 상태에서 연결하고, OLED VCC를 5V에 연결하지 않습니다.

## 처음 사용하기

1. [배선·업로드 안내](docs/hardware-and-upload.md)에 따라 `firmware/Keyring/Keyring.ino`를 업로드합니다.
2. 시리얼 모니터에서 기기의 Wi-Fi 이름을 확인합니다. 기기별 이름은 `Keyring-XXXXXX`입니다.
3. 스마트폰에서 해당 Wi-Fi에 접속합니다. 기본 수업용 암호는 `keyring123`입니다.
4. 인터넷에 연결되지 않았다는 안내가 나오면 이 Wi-Fi 연결을 유지합니다. 브라우저 주소창에 `http://192.168.4.1`을 입력합니다.
5. 캐릭터·감정·화면 모드를 고르고 적용합니다. 저장 성공 안내와 실제 OLED를 모두 확인합니다.
6. 날씨는 아래의 **인터넷 없이 날씨 가져오기** 절차를 사용합니다.

키링 Wi-Fi는 설정용 AP이며 인터넷 공유기가 아닙니다. 캐릭터 설정과 저장에는 인터넷이 필요 없습니다. 기본 암호는 수업 편의를 위한 공용 암호이므로 개인 정보나 민감한 자료를 입력하지 말고, 사용을 마치면 전원을 분리합니다.

## 캐릭터와 화면

- 캐릭터: 토끼, 고양이, 곰, 거북이, 기본 몬스터
- 감정: 행복, 신남, 졸림, 슬픔, 화남, 사랑
- 애니메이션: 눈 깜빡임, 작은 움직임, 감정별 표정과 하트·졸음 표현
- 화면 모드: 친구만(캐릭터), 날씨만, 번갈아(자동 전환)

픽셀 렌더러가 만든 128×64 흑백 프레임을 OLED와 웹 미리보기가 함께 사용합니다. 미리보기는 확대되어 보이지만 픽셀 비율은 같습니다. 화면은 일정 간격으로 갱신하고, 변경된 프레임만 전송합니다. OLED를 지우는 빈 화면을 중간에 따로 전송하지 않습니다.

## 인터넷 없이 날씨 가져오기

키링 자체가 인터넷에 접속하지 않아도 다음 순서로 실제 예보를 옮길 수 있습니다.

1. 인터넷이 되는 상태에서 이 프로젝트의 웹 화면을 엽니다. 교사가 미리 준비한 웹 화면 또는 PC에서 실행한 개발 서버를 사용할 수 있습니다.
2. 지역을 고르고 실제 날씨를 받은 뒤 날씨 JSON 파일을 다운로드합니다.
3. 스마트폰을 키링 Wi-Fi로 바꿔 연결합니다.
4. `http://192.168.4.1`에서 내려받은 날씨 파일을 가져와 기기에 저장합니다.
5. 저장 성공 안내, 출처와 마지막 업데이트 시각을 확인합니다. 화면 모드를 **날씨만** 또는 **번갈아**로 바꾸고 적용합니다.

휴대전화가 Wi-Fi와 이동통신을 동시에 사용할 수 있으면 기기 화면에서 직접 날씨를 받을 수도 있습니다. 휴대전화별 동작이 다르므로 수업에서는 파일 가져오기 방식을 준비하세요. 자세한 설명은 [날씨와 시간 처리](docs/weather.md)에 있습니다.

실제 날씨는 Open-Meteo를 이용하고, 연습용 데이터는 항상 샘플로 표시합니다. 예보를 3시간 넘게 갱신하지 않았거나 예보 범위를 벗어나면 오래된 예보로 표시합니다. **전원을 완전히 껐다 켜면 시계는 미확인 상태가 됩니다.** 스마트폰 설정 화면에 다시 접속해 시간을 맞추기 전까지 저장된 예보를 실시간 정보라고 표시하지 않습니다.

Open-Meteo의 무료 API는 비상업적 사용 조건이 적용됩니다. 유료 수업·판매 제품 등 상업적 사용 여부는 배포 전에 [공식 이용약관](https://open-meteo.com/en/terms)을 확인하고 적절한 이용 방식을 선택해야 합니다. 기상 데이터 출처는 Open-Meteo, 라이선스는 [CC BY 4.0](https://open-meteo.com/en/licence)입니다. 안전 판단이나 재난 경보용으로 사용하지 않습니다.

## 개발·빌드·테스트

클라우드 설치 스크립트는 Linux x86_64용입니다. 기본 도구로 Python 3.12 이상, Node.js 22 이상, C++ 컴파일러가 필요합니다. `tools/setup.sh`는 Arduino CLI **1.3.1**, ESP32 Arduino Core **3.3.7**, 고정 버전 라이브러리를 저장소 상위의 `.tooling`(이 환경에서는 `/workspace/.tooling`)에 준비하고 공식 배포 체크섬을 검증합니다. 웹 테스트 의존성은 `npm ci`로 설치합니다. Windows·macOS에서는 [Arduino IDE 안내](docs/hardware-and-upload.md)를 사용합니다.

```sh
cd /workspace/keyring
bash tools/setup.sh
bash tools/test.sh
bash tools/build.sh
npm run test:e2e
```

웹 개발 서버는 다음과 같이 실행합니다.

```sh
python3 tools/dev_server.py --port 8000
```

기본 개발 서버는 기기 API가 없는 독립 웹 화면으로 실행됩니다. 개발·브라우저 테스트용 모의 기기는 `--mock` 옵션으로 켜며, 모의 응답은 실물 ESP32 검증을 대신하지 않습니다. 스마트폰에서 PC 개발 서버에 접속하려면 PC와 스마트폰이 같은 네트워크에 있어야 하며, PC의 네트워크 주소를 사용해야 합니다. 기본 서버는 PC 내부 접속용이므로 스마트폰에도 열려면 `--host 0.0.0.0` 옵션을 추가합니다. 키링 AP 주소는 실제 펌웨어를 업로드한 기기에 접속했을 때만 사용할 수 있습니다.

웹 파일을 수정한 후에는 펌웨어용 웹 자산을 다시 생성하고 빌드해야 합니다. 웹 자산은 펌웨어에 포함되므로 별도의 SPIFFS/LittleFS 파일 업로드는 필요하지 않습니다. 세부 명령과 테스트 범위는 [개발 구조·API](docs/development.md)를 참고하세요.

## 폴더 구성

```text
firmware/Keyring/   Arduino 스케치, 픽셀 렌더러, 저장·시간 규칙, 내장 웹 자산
web/               스마트폰 UI, 공통 픽셀 프레임, 날씨 변환 모듈
tools/             설치·빌드·자산 생성·개발 서버
tests/             C++ 및 JavaScript 테스트
docs/              배선, 업로드, 학생·교사 안내, 날씨와 API 설명
```

## 검증 범위

이 저장소의 자동 테스트는 픽셀 데이터, 설정·시간·날씨 규칙과 웹 동작을 검증하며, ESP32-C3 타깃 빌드는 업로드 가능한 펌웨어의 컴파일을 검증합니다. **클라우드에서 실물 보드에 업로드하거나 물리 OLED를 관찰한 것은 아닙니다.** 사용자가 앞서 확인한 `OLED OK`는 기존 하드웨어·배선 테스트 결과이며 이번 통합 펌웨어의 실물 검증 결과와 구분합니다.

수업 전에 [교사용 확인표](docs/teacher-guide.md)의 업로드, OLED 표시, 설정 저장 후 전원 재연결, 인터넷 없는 날씨 표시, 시계 미확인 표시, 초기화를 실제 기기로 확인하세요. 이번 작업의 실행 결과와 남은 제한은 작업 완료 보고에서 확인할 수 있습니다.

현재 클라우드의 [빌드·테스트 실행 기록](docs/verification.md)에는 통과한 검사와 아직 확인하지 못한 실물·외부 API 항목을 구분해 기록했습니다.
