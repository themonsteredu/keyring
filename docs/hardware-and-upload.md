# 배선과 Arduino IDE 업로드

## 확인된 부품

- ESP32-C3 SuperMini
- 0.96인치 I2C SSD1306 OLED, 128×64 흑백
- 암암 점퍼선 4개
- USB-C 데이터 케이블

현재 전원은 USB입니다. 배터리와 충전 회로는 아직 선정하지 않았으므로 이 안내에는 배터리 연결을 포함하지 않습니다. 보드에 충전 기능이 있다고 가정하거나 리튬 배터리를 GPIO·3.3V 핀에 직접 연결하지 않습니다.

## 배선

USB 케이블을 분리하고 핀 이름을 읽은 뒤 연결합니다. OLED 핀의 물리적 순서는 제조사마다 다를 수 있으므로 위치 대신 **실크 인쇄 이름**을 확인합니다.

| OLED 핀 | 연결할 보드 핀 | 확인할 내용 |
| --- | --- | --- |
| GND | G | 전원 기준선 |
| VCC | 3.3V | 5V 사용 금지 |
| SDA | GPIO4 | 데이터, 고정 핀 |
| SCL | GPIO5 | 클록, 고정 핀 |

이 배선은 사용자가 기존 `OLED OK` 화면 출력에 성공한 배선입니다. 다른 보드 예제의 기본 I2C 핀으로 바꾸지 않습니다. 펌웨어는 `Wire.begin(4, 5)`를 사용합니다.

## 블록코딩 기능을 추가할 때

이전 펌웨어를 이미 업로드한 기기도 **새 통합 스케치를 다시 업로드**해야 합니다. 예전 펌웨어에는 `/api/program`과 `/api/program/control`이 없으므로 새 웹 편집기만 열어서는 블록 프로그램을 기기에 저장·실행할 수 없습니다. 펌웨어 폴더 전체와 새 `web_assets.h`를 함께 사용합니다. GPIO4·GPIO5 배선과 ESP32 Arduino Core 3.3.7은 그대로 유지합니다.

Google Blockly와 한국어 편집기 자산도 생성 헤더에 들어 있습니다. 별도로 CDN에 접속하거나 파일 시스템 이미지를 업로드할 필요는 없습니다.

## 업로드용 파일 받기

저장소의 [Arduino IDE용 ZIP](../downloads/Keyring-Arduino.zip)을 내려받아 압축을 풉니다. **`Keyring/Keyring.ino`**를 열고 같은 폴더의 모든 `.h` 파일을 함께 둡니다. `.ino` 하나만 다른 폴더로 옮기면 렌더러·프로그램 해석기·내장 웹 자산을 찾지 못합니다. 전체 저장소를 받은 경우에는 `firmware/Keyring/Keyring.ino`를 그대로 열어도 됩니다.

이 ZIP은 소스 스케치이며, 라이브러리 설치와 Arduino IDE의 컴파일·USB 업로드는 아래 순서로 진행합니다. 이전에 받은 ZIP 대신 블록코딩 기능이 포함된 최신 패키지를 사용하세요.

## Arduino IDE 준비

1. Arduino IDE의 추가 보드 매니저 URL에 Espressif 공식 ESP32 패키지 주소를 등록합니다.

   ```text
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

2. 보드 매니저에서 **esp32 by Espressif Systems 3.3.7**을 설치합니다.
3. 보드를 **ESP32C3 Dev Module**로 선택합니다.
4. 라이브러리 매니저에서 다음 고정 버전 라이브러리를 설치합니다. 저장소의 `tools/setup.sh`도 같은 버전을 사용합니다.

   | 라이브러리 | 버전 | 용도 |
   | --- | --- | --- |
   | Adafruit SSD1306 | 2.5.16 | OLED 버퍼·화면 전송 |
   | Adafruit GFX Library | 1.12.5 | 글자·도형 |
   | Adafruit BusIO | 1.17.4 | Adafruit I2C 지원 |
   | ArduinoJson | 7.4.2 | 설정과 날씨 JSON |

5. `firmware/Keyring/Keyring.ino`를 엽니다. 같은 폴더의 헤더 파일도 함께 있어야 합니다.
6. 보드 옵션에서 **USB CDC On Boot: Enabled**, Flash Size **4MB**, Partition Scheme **Huge APP (3MB No OTA/1MB SPIFFS)**를 선택합니다. 이 프로젝트는 SPIFFS에 파일을 업로드하지 않으며 이 파티션은 앱 공간 확보를 위해 사용합니다.
7. USB 데이터 케이블로 연결하고 해당 포트를 선택합니다.
8. 먼저 검증/컴파일한 뒤 업로드합니다. 업로드가 끝나면 시리얼 모니터를 **115200 baud**로 엽니다.

웹 파일은 생성된 `web_assets.h`에 포함됩니다. Arduino IDE만 사용하는 경우 저장소에 포함된 생성 파일을 그대로 사용할 수 있습니다. 웹 소스를 수정한 개발자는 빌드 도구로 자산을 다시 생성해야 합니다.

## 첫 부팅 확인

1. OLED에 기본 캐릭터가 보이는지 확인합니다.
2. 시리얼 모니터에서 `Keyring-XXXXXX` 형태의 Wi-Fi 이름과 OLED 초기화 결과를 확인합니다.
3. 스마트폰 Wi-Fi에서 해당 이름을 선택하고 `keyring123`으로 접속합니다.
4. 인터넷 없음 알림이 나와도 연결을 유지하고 브라우저에 `http://192.168.4.1`을 입력합니다. 검색창이 아니라 주소창에 입력합니다.
5. **꾸미기** 탭에서 캐릭터를 바꾸고 **이 모습 키링에 저장**을 눌러 OLED와 비교합니다.
6. USB 전원을 분리한 뒤 재연결하여 저장한 캐릭터·감정·화면 모드가 복원되는지 확인합니다.
7. **블록 코딩**에서 기다리기가 포함된 프로그램을 저장·실행합니다. USB를 분리·재연결하면 실행을 켜 둔 프로그램이 첫 블록부터 시작하는지 확인합니다. 정지한 프로그램은 재부팅 후에도 자동 실행하지 않아야 합니다.

## OLED가 검게 보일 때

전원을 분리한 뒤 GND·3.3V·GPIO4·GPIO5 연결을 다시 확인합니다. 가장 먼저 SDA/SCL이 뒤바뀌지 않았는지 확인하세요. **다른 GPIO로 옮기면서 해결하려 하지 않습니다.**

펌웨어는 일반적인 주소 `0x3C`를 확인하고 `0x3D`도 확인합니다. 시리얼 모니터의 OLED 오류를 읽습니다. 웹 설정이 열리는데 OLED만 안 보이면 보드 전체의 Wi-Fi 문제와 구분할 수 있습니다. 연결이 느슨한 점퍼선, 디스플레이의 실제 해상도·컨트롤러 종류도 확인합니다. SH1106 전용 제품은 SSD1306과 다르므로 모델을 확인해야 합니다.

필요한 경우 아래 별도 스케치로 I2C 주소만 확인할 수 있습니다. 테스트 후 다시 통합 스케치를 업로드합니다. 핀은 그대로 유지합니다.

```cpp
#include <Wire.h>

void setup() {
  Serial.begin(115200);
  delay(1000);
  Wire.begin(4, 5);
  for (uint8_t address = 1; address < 127; ++address) {
    Wire.beginTransmission(address);
    if (Wire.endTransmission() == 0) {
      Serial.printf("I2C device: 0x%02X\n", address);
    }
  }
}

void loop() {}
```

## 업로드·접속이 안 될 때

| 현상 | 확인 순서 |
| --- | --- |
| 포트가 안 보임 | 충전 전용이 아닌 데이터 케이블인지 확인 → 다른 USB 포트 확인 → OS 장치 목록 확인 |
| 업로드 연결 실패 | 선택한 포트·보드 확인 → 시리얼 모니터 종료 → 보드의 BOOT/RESET 절차를 해당 보드 설명에 따라 사용 |
| 시리얼 글자가 안 보임 | 115200 baud, USB CDC On Boot Enabled 확인 → 업로드 후 포트가 바뀌었는지 확인 |
| Wi-Fi 이름이 안 보임 | USB 전원 확인 → 부팅 로그 확인 → 다른 키링의 이름과 혼동하지 않았는지 확인 |
| 휴대전화가 자꾸 다른 Wi-Fi로 이동 | 인터넷 없는 네트워크에 계속 연결하는 옵션 선택, 자동 전환 잠시 해제 |
| 설정 페이지가 열리지 않음 | 해당 Keyring Wi-Fi 연결 확인 → `http://192.168.4.1` 직접 입력 → 일반 브라우저 사용 |
| 날씨를 못 가져옴 | AP에는 인터넷이 없으므로 인터넷 연결 상태에서 파일을 먼저 받아 가져오기 |
| 재부팅 후 날씨에 시간 미확인 | 정상 동작. 스마트폰 설정 화면에 접속해 현재 시간을 다시 동기화 |
| 프로그램 저장이 지원되지 않음 | 기존 펌웨어인지 확인하고 새 통합 스케치를 업로드. 웹 편집기 갱신만으로 기기 API는 추가되지 않음 |
| 고른 표정이 곧 다시 바뀜 | 실행 중인 블록 프로그램 확인. 꾸미기에서 적용하면 프로그램이 정지함 |

## 꾸미기와 전원

모루 철사가 보드 핀·납땜부·USB 접점에 닿지 않도록 절연합니다. USB 단자와 케이블을 당기는 구조를 피하고, 디스플레이 화면과 커넥터가 눌리지 않도록 공간을 둡니다. 수업용 케이스는 전원을 분리할 수 있어야 합니다. 전원이 켜진 채 부품을 뜯거나 재배선하지 않습니다.
