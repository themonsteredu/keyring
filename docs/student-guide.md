# 학생용: 내 마음을 보여 주는 키링

우유팩 케이스 속 화면에 내가 고른 표정이 나타납니다. 전원은 USB 케이블로 연결합니다.

## 1차시: 표정과 움직임 만들기

### 연결하기

전원을 뺀 상태에서 네 가닥을 연결하고 선생님께 확인받습니다.

| OLED | ESP32-C3 |
| --- | --- |
| GND | G |
| VCC | 3.3V |
| SDA | GPIO4 |
| SCL | GPIO5 |

1. USB를 꽂습니다.
2. 스마트폰 Wi-Fi에서 내 **`Keyring-XXXXXX`**를 고릅니다. 암호는 **`keyring123`**입니다.
3. 인터넷이 없다는 안내가 나와도 연결을 유지합니다.
4. 브라우저에서 **`http://192.168.4.1`**을 엽니다.

화면 아래 **도움말**에서도 연결 방법을 볼 수 있습니다.

### 표정 고르기

1. **꾸미기**에서 행복·신남·졸림·슬픔·화남·사랑 중 하나를 누릅니다.
2. 미리보기에서 도톰한 눈과 입, 깜빡임을 봅니다.
3. **키링에 담기**를 누르고 저장 안내와 실제 OLED를 확인합니다.

눈 모양도 바꾸고 싶으면 **눈 모양 바꾸기**를 펼칩니다. 말랑눈·초롱눈·웃음눈·콩알눈·네모눈이 있습니다. 선생님과 USB를 뺐다가 다시 꽂아 같은 표정이 나오는지 확인하세요.

### 블록으로 순서 만들기

**블록 코딩**에서 시작 블록 아래에 연결합니다.

```text
키링 시작할 때
말랑눈으로 바꾸기
행복한 표정
1초 기다리기
사랑하는 표정
1초 기다리기
```

- **실행**: 브라우저에서 먼저 보기
- **반복**: 마지막 블록 뒤에 처음부터 다시 하기
- **키링에 담기**: 연결된 실제 키링에 저장하고 실행하기

표정 사이에 기다리기를 넣어야 각각의 표정을 볼 수 있습니다. [블록코딩 안내](block-coding.md)에 더 많은 예제가 있습니다.

## 2차시: 날씨와 나만의 케이스

### 날씨 가져오기

인터넷이 될 때 [온라인 키링 스튜디오](https://keyring-swart.vercel.app)에서 준비합니다.

1. **날씨**에서 지역을 고르고 **날씨 받기**를 누릅니다.
2. **파일 · 연습 → 파일 저장**으로 날씨 파일을 받습니다.
3. 내 키링 Wi-Fi로 바꾸고 `http://192.168.4.1`을 엽니다.
4. **날씨 → 파일 · 연습 → 불러오기**에서 준비한 파일을 고릅니다. 연결된 키링에 저장됩니다.
5. **꾸미기 → 화면**에서 **날씨** 또는 **번갈아**를 고르고 **키링에 담기**를 누릅니다.

선생님이 준비해 준 날씨 파일이 있다면 3번부터 합니다.

### 날씨 읽기

큰 그림은 날씨, `24°`는 온도, 물방울 옆 `58%`는 습도입니다. 습도는 우리 동네의 예보 값입니다. 키링이 교실의 습도를 재는 것은 아닙니다.

| 표시 | 할 일 |
| --- | --- |
| 연습 날씨 | 실제 바깥 날씨가 아닌 연습용임을 기억하기 |
| 지난 예보 | 새 날씨 받아서 저장하기 |
| 시각 확인 | 설정 화면을 다시 열거나 **파일 · 연습 → 시각 맞추기** 누르기 |
| 날씨 없음 | 날씨 파일 가져오기 |
| `--%` | 습도가 없는 옛 파일이므로 새 날씨 받기 |

웹에서 **24시간 예보**를 펼치면 이후 날씨를 볼 수 있습니다. **받은 시각 · 출처**를 펼치면 언제 받은 예보인지 확인할 수 있습니다. USB를 뺐다 꽂으면 저장된 예보는 남지만 시각을 다시 맞춰야 합니다.

### 날씨로 표정 바꾸기

날씨 조건 블록으로 **비이면 슬픔, 아니면 행복**을 만들어 보세요. 조건은 키링에 저장된 날씨를 읽습니다. 실제 날씨인지 연습용인지 먼저 확인합니다.

꾸미기에서 다른 표정을 담으면 블록 프로그램은 멈추고 고른 표정이 나옵니다. 블록 프로그램을 다시 실행하려면 **블록 코딩 → 키링에 담기**를 누릅니다.

### 케이스 꾸미기

전원을 빼고 선생님과 우유팩 케이스에 부품을 고정합니다. 스티커와 모루는 화면·USB 단자를 가리지 않게 붙입니다. 모루 철사가 보드의 금속 핀에 닿지 않게 하고, 케이블과 점퍼선을 세게 당기지 않습니다.

완성 후 좋아하는 표정과 내가 만든 블록 순서를 친구에게 소개해 보세요.
