# 학생용: 내 마음을 보여 주는 키링

오늘 만들 것은 내 캐릭터와 표정이 움직이는 작은 전자기기입니다. 키링 스튜디오의 **꾸미기·블록코딩·날씨** 화면을 사용합니다. 블록을 연결하면 내가 정한 순서대로 실제 키링이 움직입니다. 현재는 USB 케이블로 전원을 공급합니다. 배터리가 달린 완제품처럼 들고 다닐 수 있는 상태는 아닙니다.

## 1차시: 캐릭터를 만나기

### 1. 연결하기

선생님과 함께 전원을 뺀 상태에서 연결합니다.

| 화면의 핀 | 보드의 핀 |
| --- | --- |
| GND | G |
| VCC | 3.3V |
| SDA | GPIO4 |
| SCL | GPIO5 |

선 색깔보다 핀 이름이 중요합니다. 선을 다 연결한 뒤 선생님의 확인을 받고 USB를 꽂습니다. 화면에 캐릭터가 보이면 다음 단계로 넘어갑니다.

### 2. 내 키링 찾기

1. 내 키링의 Wi-Fi 이름을 선생님에게 확인합니다. `Keyring-` 뒤에 붙은 여섯 글자를 적어 두세요.
2. 스마트폰의 Wi-Fi 목록에서 내 키링을 선택합니다.
3. 암호 `keyring123`을 입력합니다.
4. 인터넷이 없다는 메시지가 나오면 이 Wi-Fi에 계속 연결합니다.
5. 브라우저 주소창에 `http://192.168.4.1`을 입력합니다.

이 Wi-Fi는 키링과 스마트폰을 연결하는 통로입니다. 인터넷이 없어도 캐릭터를 고를 수 있습니다. 친구 키링의 Wi-Fi에 들어가지 않도록 이름을 확인하세요.

### 3. 내 캐릭터 고르기

**꾸미기** 탭에서 토끼·고양이·곰·거북이·몬스터 중 하나를 고릅니다. 행복·신남·졸림·슬픔·화남·사랑 중 오늘 표현하고 싶은 감정을 고릅니다.

미리보기에서 눈 깜빡임과 표정을 살펴보세요. 마음에 들면 **이 모습 키링에 저장**을 누릅니다. 저장되었다는 안내가 나온 뒤 실제 OLED도 확인합니다. 화면에서 고르기만 하고 적용하지 않은 설정은 키링에 저장되지 않습니다.

### 4. 저장 확인하기

선생님과 함께 USB를 뺐다가 다시 꽂아 보세요. 내 캐릭터와 감정이 다시 나오면 저장 성공입니다. 키링은 전원이 꺼져도 설정을 기억하지만, 현재 시각까지 정확하게 기억하는 시계는 아닙니다.

### 5. 블록으로 움직이는 순서 만들기

**블록 코딩** 화면에서 시작 블록 아래에 다음 순서로 연결합니다.

```text
키링 시작할 때
토끼로 바꾸기
행복한 표정
1초 기다리기
사랑하는 표정
1초 기다리기
```

먼저 **미리 실행**을 눌러 봅니다. 행복한 표정이 바로 사라지지 않도록 기다리기 블록을 넣습니다. 반복을 켜면 마지막 블록 다음에 첫 블록으로 돌아갑니다. 같은 표정만 보인다면 블록이 서로 연결되었는지, 기다리는 시간이 있는지 확인하세요.

키링 Wi-Fi에 연결된 화면에서 **키링에 저장**을 누르면 프로그램이 기기에 저장되고 실행됩니다. 브라우저에서만 실행한 것은 아직 실제 키링에 저장된 프로그램이 아닙니다. [블록코딩 안내](block-coding.md)에서 파일로 옮기는 방법과 반복 블록 예제를 볼 수 있습니다.

## 2차시: 날씨로 달라지는 표정과 나만의 모습

### 1. 날씨 파일 가져오기

수업 전에 선생님이 실제 날씨 파일을 준비했는지 확인합니다. 인터넷이 되는 웹 화면에서 지역을 고르고 받은 파일을 사용합니다.

1. 키링 Wi-Fi에 접속하고 설정 화면을 엽니다.
2. **미리 받은 날씨 파일 불러오기**를 눌러 준비한 JSON 파일을 고릅니다. 연결된 기기에는 확인된 파일이 자동으로 저장됩니다.
3. 지역, 업데이트 시각, 실제 데이터인지 샘플인지 확인합니다.
4. 저장 성공 안내를 확인한 뒤 화면 모드를 **날씨** 또는 **번갈아 보기**로 고르고 적용합니다.
5. OLED에서 온도, 날씨 그림, 시간별 예보를 살펴봅니다.

키링 Wi-Fi에는 인터넷이 없으므로 인터넷에서 날씨를 받는 일과 키링에 파일을 보내는 일은 나누어 할 수 있습니다. 연결이 안 될 때 계속 버튼을 누르기보다 선생님과 현재 Wi-Fi를 확인하세요.

### 2. 표시를 읽기

| 표시 | 뜻 | 할 일 |
| --- | --- | --- |
| 실제 날씨 / SYNCED | 최근에 받은 실제 예보 | 지역과 업데이트 시각 확인 |
| 샘플 / SAMPLE | 기능을 연습하기 위한 가짜 예보 | 실제 바깥 날씨라고 말하지 않기 |
| 오래된 예보 / OLD FORECAST | 받은 지 오래되었거나 예보 범위를 지남 | 새 파일을 받아 저장하기 |
| 시간 미확인 / TIME UNKNOWN | 지금 몇 시인지 기기가 아직 모름 | 설정 화면을 다시 열거나 **휴대폰 시각 맞추기** 누르기 |
| 날씨 없음 / NO WEATHER | 저장된 날씨가 없음 | 날씨 파일 가져오기 |

날씨 예보는 앞으로 일어날 일을 예상한 정보입니다. 항상 실제 날씨와 같지는 않습니다. 마지막으로 받은 시각을 확인하는 습관을 가져 봅시다.

### 3. 날씨에 따라 다르게 표현하기

날씨 조건 블록으로 **비이면 슬픈 표정, 아니면 행복한 표정**처럼 두 가지 길을 만듭니다. 어느 길로 가는지 말해 보고 실행합니다. 연습용 날씨나 오래된 예보도 저장된 코드가 있으면 조건에 쓰입니다. 실제 날씨인지, 업데이트한 시각은 언제인지 선생님과 확인하세요. 날씨가 없으면 아니면 쪽을 실행합니다. 조건은 날씨를 새로 받는 버튼이 아니라 저장된 데이터를 읽는 블록입니다.

프로그램의 시작·정지와 꾸미기 화면의 직접 적용을 비교합니다. 꾸미기에서 적용하면 프로그램이 멈춰 내가 고른 표정이 유지됩니다. 실행을 켠 프로그램은 전원을 다시 연결하면 처음부터 시작하지만, 정지한 프로그램은 자동으로 시작하지 않습니다.

### 4. 꾸미기

전원을 분리하고 선생님과 함께 모루인형 재료로 꾸밉니다. 화면이 잘 보이는 창을 남기고, 철사가 보드의 금속 핀에 닿지 않도록 합니다. USB 케이블과 점퍼선을 세게 당기지 않습니다. 열이 나거나 이상한 냄새가 나면 즉시 선생님에게 알립니다.

### 5. 소개하기

- 내 캐릭터와 감정은 무엇인가요?
- 어떤 표정이나 움직임이 가장 잘 보이나요?
- 블록의 순서를 바꾸면 결과가 어떻게 달라지나요?
- 기다리기와 반복은 각각 어떤 일을 하나요?
- 날씨 조건이 참일 때와 거짓일 때 어떤 블록이 실행되나요?
- 인터넷이 없어도 되는 기능은 무엇인가요?
- 날씨의 마지막 업데이트 시각은 왜 확인해야 할까요?
- 전원을 껐다 켜면 캐릭터는 남는데 시각은 다시 확인하는 이유는 무엇일까요?

## 처음부터 다시 만들고 싶을 때

**키링 전체 초기화**를 누르면 캐릭터·감정·화면 모드와 저장한 날씨·프로그램이 기본 상태로 돌아갑니다. 확인 화면을 읽고 선택하세요. 다른 친구의 키링은 초기화하지 않습니다.
