# 교사용: 제작 준비와 2차시 운영

## 수업 목표와 범위

학생은 부품을 올바르게 연결하고, 스마트폰으로 캐릭터와 감정을 선택해 저장하며, 실제 날씨와 샘플·오래된 예보를 구분합니다. 2차시에는 모루인형 재료로 꾸미고 결과를 설명합니다.

기본 구성은 ESP32-C3 SuperMini, SSD1306 I2C OLED, 점퍼선 4개, USB-C 케이블입니다. 납땜과 배터리 조립은 수업 범위에 포함하지 않습니다. 보드나 OLED에 핀 헤더가 없다면 교사가 수업 전에 별도로 준비해야 하며, 학생이 무리하게 선을 끼워 고정하지 않도록 합니다. USB를 뺀 상태로 조립하고 교사가 배선을 확인한 뒤 전원을 연결합니다.

## 수업 전 준비

1. 실제 사용할 보드 한 대로 아래 실물 확인표를 먼저 완료합니다.
2. 모든 보드에 같은 통합 펌웨어를 미리 업로드합니다. 수업 시간에 드라이버·라이브러리 설치와 전체 업로드를 함께 진행하지 않아도 됩니다.
3. 각 보드의 `Keyring-XXXXXX` 이름을 기록하고 키트·학생 자리표에 같은 표시를 붙입니다. SSID의 마지막 여섯 글자는 기기별 MAC 주소에서 만들어집니다.
4. 스마트폰 브라우저에서 인터넷 없는 Wi-Fi에 연결을 유지하는 방법을 확인합니다. 자동으로 이동통신이나 다른 Wi-Fi로 전환하는 기기는 사전에 연습합니다.
5. 실제 수업 지역의 날씨 파일을 수업 직전에 받습니다. **실제 예보 파일과 샘플 파일을 이름과 안내 문구로 구분**합니다. 오래전에 받은 실제 파일을 최신 날씨라고 소개하지 않습니다.
6. 날씨 파일을 스마트폰의 파일 앱에서 고를 수 있는지 확인합니다. 휴대전화 운영체제·브라우저별 다운로드와 파일 선택 동작이 다를 수 있습니다.
7. 꾸미기 재료가 보드 접점을 단락시키지 않도록 절연 재료와 케이블 고정 방법을 준비합니다.
8. 예비 USB 데이터 케이블, 점퍼선, 정상 작동이 확인된 OLED·보드를 준비하면 고장 구분에 도움이 됩니다.

기기의 AP에는 인터넷이 없습니다. 학생 휴대전화마다 AP 접속 중 이동통신을 사용할 수 있다고 가정하지 마세요. 수업에서는 **인터넷 연결 → 날씨 JSON 다운로드 → 키링 AP 연결 → 파일 가져오기** 순서를 기본으로 삼습니다. 학교 공유기·계정 정보를 기기에 입력할 필요는 없습니다.

30대 안팎의 AP를 동시에 켜면 2.4GHz 혼잡이 발생할 수 있습니다. 자리별로 한꺼번에 접속을 시도하기보다 소그룹 단위로 전원을 연결하고 저장을 마친 기기는 연결을 종료합니다. 기기별 Wi-Fi 이름을 확인해 친구 기기에 적용하지 않도록 지도합니다. 기본 암호는 모든 기기에서 동일하므로 수업 외 공개 장소에서 계속 켜 두지 않습니다.

## 1차시: 연결·표정·저장, 40분

| 시간 | 활동 | 교사의 확인 |
| --- | --- | --- |
| 0~5분 | 완성 예시 관찰, 캐릭터와 감정 이야기 | 화면이 작으므로 큰 표정으로 의미를 전달함 |
| 5~15분 | 핀 이름을 읽고 네 가닥 연결 | GND→G, VCC→3.3V, SDA→GPIO4, SCL→GPIO5 |
| 15~22분 | 교사 배선 확인, USB 전원, 내 Wi-Fi 찾기 | 인터넷 없음 안내에도 연결 유지 |
| 22~32분 | 캐릭터·감정 선택, 미리보기, 적용 | 저장 성공 안내와 실제 OLED 일치 |
| 32~37분 | 전원을 분리·재연결해 저장 확인 | 설정 복원과 시계 미확인을 구분 |
| 37~40분 | 오늘 선택한 표정 소개 | 감정에는 정답이 없고 선택은 학생이 함 |

## 2차시: 날씨·꾸미기·공유, 40분

| 시간 | 활동 | 교사의 확인 |
| --- | --- | --- |
| 0~5분 | 전 차시 복습, 인터넷과 기기 연결 구분 | 설정은 오프라인에서도 가능 |
| 5~15분 | 준비한 날씨 파일 가져오기, 시간 동기화 | 지역·출처·업데이트 시각·샘플 표시 |
| 15~20분 | 날씨/자동 화면과 시간별 예보 관찰 | 예보와 실제 관측의 차이, 오래된 예보 표시 |
| 20~33분 | 전원을 빼고 모루인형으로 꾸미기 | 철사와 접점 절연, 케이블 당김 방지 |
| 33~38분 | 완성품 발표, 친구 작품 관찰 | 내 선택·인터넷 없는 기능·업데이트 시각 설명 |
| 38~40분 | 전원 분리, 부품 정리 | USB 전원 방식임을 재확인 |

시간이 부족하면 교사가 배선을 사전에 준비하고 학생은 핀 이름을 확인하는 활동부터 시작할 수 있습니다. 날씨 API 이용이나 파일 공유가 막히면 **연습용 샘플**로 인터페이스를 배운 뒤 실제 예보 동기화를 별도 시연합니다. 샘플을 실제 날씨로 소개하지 않습니다.

## 실물 확인표

아래 항목은 클라우드 빌드로 확인할 수 없습니다. 수업 전 실제 부품으로 수행하고 결과를 기록합니다.

| 확인 항목 | 합격 기준 | 결과 기록 |
| --- | --- | --- |
| 배선 | GPIO4/5를 유지하고 VCC 3.3V, GND 공통 | 미확인 |
| 업로드·부팅 | 지정 보드·코어에서 업로드 성공, 부팅 로그 확인 | 미확인 |
| OLED | 128×64 화면에서 캐릭터가 선명하고 반복 깜빡임·빈 화면 없음 | 미확인 |
| 30가지 조합 | 5캐릭터×6감정 구분, 잘림·좌우 뒤집힘 없음 | 미확인 |
| 미리보기 일치 | 같은 캐릭터·감정에서 웹과 OLED 모양이 같음 | 미확인 |
| 설정 저장 | 적용 성공 후 USB 재연결해 같은 설정 복원 | 미확인 |
| 실패 안내 | 기기 연결을 끊으면 저장 성공으로 오해시키지 않음 | 미확인 |
| 실제 날씨 | 준비한 실제 파일 저장, 온도·아이콘·24개 시간별 예보 확인 | 미확인 |
| 인터넷 단절 | 모바일 인터넷 없이도 저장된 예보 표시 | 미확인 |
| 전원 재연결 | 저장 예보 유지, 시간 미확인 표시, 접속 후 시간 회복 | 미확인 |
| 오래된 데이터 | 3시간 초과 파일이 최신으로 표시되지 않음 | 미확인 |
| 샘플 | OLED와 웹 모두 샘플 표시를 유지 | 미확인 |
| 초기화 | 확인 후 기본 설정 복원 및 날씨 삭제 | 미확인 |
| 장시간 관찰 | 수업 시간 동안 과열·비정상 재부팅·화면 이상 없음 | 미확인 |
| 꾸미기 | 모루 철사와 접점이 닿지 않고 화면·단자에 힘이 가해지지 않음 | 미확인 |

자동 테스트와 ESP32-C3 타깃 빌드는 소프트웨어 검증입니다. 사용자가 기존에 확인한 `OLED OK` 출력은 배선·OLED 통신의 선행 확인이며 이번 통합 펌웨어의 위 항목을 대신하지 않습니다.

## 날씨 서비스 사용 판단

Open-Meteo 무료 API는 비상업적 이용 조건을 확인해야 합니다. 특히 유료 교육 상품이나 판매용 키링에 포함할 경우 해당 용도가 허용된다고 임의로 판단하지 말고 [공식 약관](https://open-meteo.com/en/terms)을 검토합니다. 트래픽 제한과 서비스 가용성은 바뀔 수 있으므로 수업 직전에 확인하고 파일 가져오기와 샘플을 준비합니다. 날씨 정보는 학습용이며 위험 상황의 판단 근거로 사용하지 않습니다.

이 프로젝트의 기본 화면은 위치를 도시 목록으로 선택하며 GPS 접근을 필수로 요구하지 않습니다. 학교·학생 주소 같은 개인정보를 입력할 필요가 없습니다. 키링 AP는 로컬 HTTP를 사용하고 공용 수업 암호를 제공하므로 민감한 정보를 다루는 시스템으로 사용하지 않습니다.

## 수업 후

학생별 설정을 유지하려면 초기화하지 않고 전원을 분리합니다. 다음 수업에서 저장된 날씨가 남아 있더라도 새 파일을 받아 업데이트 시각을 확인하세요. 다른 학생에게 재배부할 때는 교사가 초기화합니다. USB 케이블·모루 재료·접점 상태를 확인하고 전원이 없는 상태로 보관합니다.
