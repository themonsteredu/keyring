# 펌웨어 2.0.0 · 스튜디오 검증 기록

검증일: 2026-10-23. 대상: ESP32-C3 SuperMini, ESP32C3 Dev Module, ESP32 Arduino Core 3.3.7. USB 장치가 연결되지 않은 Linux 클라우드에서 실제 명령을 실행했습니다.

| 검사 | 결과 |
| --- | --- |
| `bash tools/setup.sh` | 공식 체크섬으로 설치한 고정 도구 재사용, 잠금 파일의 npm 의존성 설치 성공 |
| C++ 기본 설정·날씨·시계 | 75개 검증 통과 |
| C++ 캐릭터 렌더러 | 960프레임·30조합·눈 깜빡임·움직임·픽셀 순서·버퍼 경계 검사 통과 |
| C++ 프로그램 codec·실행기 | 1,216개 검증 통과. 입력 검사, 대기·반복·날씨 조건, 재시작, 원자적 설정 묶음 복원 포함 |
| JavaScript | 44개 테스트 통과: 날씨 8개, 프로그램 16개, 실제 C++ 실행기와의 비교 20개 |
| Python 모의 장치·HTTP API | 22개 테스트 통과. 실제 ESP32 NVS 기록과 구분 |
| Chromium 브라우저 | 19개 테스트 통과. 실패·건너뜀 없음 |
| 생성 자산·배포 ZIP | Blockly 13.4.0의 로컬 자산 12개, 캐릭터 atlas, 펌웨어 gzip 자산 19개와 소스 일치. ZIP CRC와 스케치·헤더 5개 일치 검사 통과 |
| `bash tools/build.sh` | ESP32-C3 RISC-V 타깃 교차 컴파일 성공 |

네이티브 C++ 검증에는 AddressSanitizer·UndefinedBehaviorSanitizer를 사용했습니다. 프로그램 codec 테스트는 ArduinoJson 7.4.2와 같은 헤더를 사용하며, 브라우저·기기 비교는 실제 펌웨어의 codec과 실행기를 컴파일한 `tools/trace_program.cpp` 결과를 비교합니다.

최종 스케치 사용량은 플래시 **1,378,099 / 3,145,728바이트**, 정적 RAM **41,612 / 327,680바이트**입니다. 보드 옵션은 USB CDC On Boot Enabled, Flash Size 4MB, **Huge APP (3MB No OTA/1MB SPIFFS)**입니다. 이 버전은 기본 앱 파티션보다 크므로 Huge APP을 선택해야 합니다.

## 확인한 사용자 흐름

브라우저 검사에서 실제 Blockly 도구상자의 블록을 마우스로 끌어 추가하고, 연결하지 않은 블록은 실행되지 않는지 확인했습니다. JSON을 편집 가능한 블록으로 불러오기, 미리 실행과 완료 화면 유지, 정지 후 수동 설정 복원, 프로그램 저장 후 재조회·모의 재부팅·중지 상태 유지, 저장 실패·잘못된 파일 거부를 확인했습니다. 오래된 펌웨어에는 업데이트 안내가 표시됩니다.

기기 API가 없는 온라인 상태에서도 블록 미리 실행과 프로그램 파일 다운로드가 작동합니다. Vercel의 실제 콘텐츠 보안 정책을 적용한 브라우저 검사도 통과했고, 편집기 코드는 외부 CDN에 의존하지 않습니다. 360px 화면에서 페이지 가로 넘침이 없으며 모바일 도구상자는 위쪽으로 배치됩니다. 브라우저 프레임 시각이 실행 버튼을 누른 시각보다 앞서는 상황에서도 프로그램이 잘못 종료되지 않는지 확인했습니다.

꾸미기·날씨 회귀 검사도 포함합니다. 30개 캐릭터·감정 조합의 Canvas 픽셀을 C++ atlas와 비교했고, 설정 저장·새로고침 복원, 24개 예보, 명시적인 샘플 표시, 인터넷 요청 실패, 전원 재시작 후 시각 미확인, 3시간 경과 시 오래된 예보 표시와 미저장 선택 보존을 확인했습니다. 날씨 화면 미리보기는 같은 5×7 글꼴·레이아웃을 사용하지만, 캐릭터와 같은 전체 프레임 일치 검사를 수행한 것은 아닙니다.

## 실물·외부 서비스에서 남은 확인

- 물리 ESP32에 새 펌웨어를 업로드하고 OLED의 그림·애니메이션·AP 접속·프로그램 순서를 확인해야 합니다. 앞선 `OLED OK`는 사용자가 확인한 별도 하드웨어 결과입니다.
- 실제 NVS 저장 후 USB 전원 분리·재연결, 쓰기 중 전원 차단, 화면 떨림과 전력 소비는 클라우드 테스트로 검증하지 못했습니다. 16KB 요청 제한은 ESP32 HTTP 서버가 본문을 수신한 뒤 적용되므로 수신 단계의 메모리 상한을 보장하지 않습니다.
- Open-Meteo의 실시간 응답 수신은 클라우드 네트워크 정책의 403 차단으로 미검증입니다. API 요청·조건·변환·오류 처리는 구현했고 샘플을 실제 수신 결과로 기록하지 않았습니다.
- 사용자가 연결한 실제 Vercel 주소와 GitHub Actions 실행 결과는 이 기록에서 검증하지 않았습니다. 로컬 브라우저 통과와 실제 서비스 배포 완료는 별개입니다.
- 배터리·충전 회로는 미정이며 USB 전원만 대상으로 합니다.

실물 확인은 [교사용 확인표](teacher-guide.md)에 따라 진행합니다.
