# 펌웨어 2.1.0 · 우유팩 표정 키링 검증 기록

검증일: 2026-10-24. 대상: ESP32-C3 SuperMini, ESP32C3 Dev Module, ESP32 Arduino Core 3.3.7. USB 장치가 연결되지 않은 Linux 클라우드에서 실제 명령을 실행했습니다.

`bash tools/test.sh`로 네이티브·JavaScript·모의 HTTP API와 생성물 검사를 실행했습니다. C++ 렌더러와 프로그램 검증 및 날씨 프레임 비교용 C++에는 AddressSanitizer·UndefinedBehaviorSanitizer를 사용했습니다. 프로그램 codec은 실제 펌웨어와 같은 ArduinoJson 7.4.2 헤더를 사용합니다. Node 의존성은 잠금 파일의 버전을 그대로 사용했습니다.

최종 스케치 사용량은 플래시 **1,340,213 / 3,145,728바이트**, 정적 RAM **41,484 / 327,680바이트**입니다. 보드 옵션은 USB CDC On Boot Enabled, Flash Size 4MB, **Huge APP (3MB No OTA/1MB SPIFFS)**입니다. 기본 앱 파티션보다 크므로 Huge APP을 선택해야 합니다. SDA GPIO4·SCL GPIO5를 유지했습니다.

## 확인한 화면과 동작

OLED는 동물 몸·귀·얼굴 테두리를 그리지 않고 큰 눈과 작은 입, 감정에 따른 하트·눈물·잠방울을 표시합니다. 저장된 `rabbit`, `cat`, `bear`, `turtle`, `monster` 값은 호환성을 유지하며 말랑눈·초롱눈·웃음눈·콩알눈·네모눈을 선택합니다. 기존 설정과 블록 파일을 계속 읽을 수 있습니다. 웹의 큰 미리보기와 선택용 작은 미리보기는 같은 흰 픽셀·검은 배경을 사용합니다.

브라우저에서 30개 눈 모양·감정 조합의 Canvas 픽셀을 C++ atlas와 비교했습니다. 날씨도 C++와 JavaScript가 같은 한글 비트맵과 픽셀 배치를 사용합니다. 별도 15개 테스트의 295개 프레임 비교에서 5개 상태, 현재 화면과 시간별 예보 4페이지, 해·구름·비·눈·번개·안개, 깜빡임, 음수·소수 온도 경계, 윤일과 연도 전환이 모두 일치했습니다. 화면 아래의 받은 날짜·시각은 예보 페이지가 바뀌어도 유지됩니다. 연습·지난 예보·시각 미확인 상태가 화면에 표시되며, 과거 자료에 현재 실시간 정보처럼 보이는 제목을 붙이지 않습니다.

실제 Blockly 도구상자의 블록을 끌어 추가하고, 연결되지 않은 블록 실행 거부, 파일 불러오기·내보내기, 미리 실행·완료 화면 유지·정지, 저장 후 재조회와 모의 재부팅, 저장 실패와 잘못된 파일 거부를 확인했습니다. 실행 중 탭을 바꾸어도 꾸미기·날씨의 안내와 미리보기를 유지하고 블록 탭으로 돌아오면 실행 결과를 보여 줍니다. 처음 예제는 짧은 행복·사랑 표정 순서입니다.

360px 화면의 가로 넘침이 없고, 모바일에서 블록 편집기와 OLED 미리보기·실행 버튼이 함께 보이는지 검사했습니다. 데스크톱 저장·저장 실패와 모바일 하단 저장을 각각 검증했습니다. 날씨 샘플·24개 예보·실제 API 요청 실패·재부팅 후 시각 미확인·3시간 경과 시 오래된 예보도 확인했습니다. 온라인에서는 기기 저장 성공을 가장하지 않고 미리보기 모드를 표시합니다. 실제 Vercel 콘텐츠 보안 정책에서 편집기가 작동하며 외부 CDN에 의존하지 않습니다.

## 온라인 배포

운영 주소는 [keyring-swart.vercel.app](https://keyring-swart.vercel.app)이며, Vercel 팀 `themonsteredu`의 기존 `keyring` 프로젝트에 연결했습니다. 배포 입력 검사는 프레임워크 Other와 웹 파일·설정 23개를 확인했습니다. 설치·빌드를 생략하고 `web`을 정적으로 제공합니다. 새 버전의 실제 배포·운영 주소 검증 결과는 배포 완료 후 기록합니다.

Arduino ZIP은 스케치·헤더 7개·글꼴 라이선스의 9파일을 포함합니다. 웹 배포와 보드 업로드는 별도입니다. 실제 보드에도 새 눈·입과 한글 날씨가 나오려면 새 ZIP의 펌웨어를 다시 업로드해야 합니다.

## 실물·외부 서비스에서 남은 확인

- 물리 ESP32에 새 펌웨어를 업로드하고 OLED의 그림·한글·애니메이션·AP 접속·프로그램 순서를 확인해야 합니다. 앞선 `OLED OK`는 사용자가 확인한 별도 하드웨어 결과입니다.
- 실제 NVS 저장 후 USB 전원 분리·재연결, 쓰기 중 전원 차단, 화면 떨림과 전력 소비는 클라우드 테스트로 검증하지 못했습니다. 16KB 요청 제한은 ESP32 HTTP 서버가 본문을 수신한 뒤 적용되므로 수신 단계의 메모리 상한을 보장하지 않습니다.
- Open-Meteo의 실제 서울 응답에서 HTTP 200과 앞으로 24개 예보 변환을 확인했습니다. 이 한 번의 수신은 서비스의 상시 가용성이나 예보 정확도를 보장하지 않습니다. 연습용 샘플을 실제 수신 결과로 기록하지 않았습니다.
- GitHub Actions의 원격 실행 결과는 이 기록에서 확인하지 않았습니다.
- 배터리·충전 회로는 미정이며 USB 전원만 대상으로 합니다. 우유팩 미리보기는 케이스 제작 치수나 조립 파일을 대신하지 않습니다.

실물 확인은 [교사용 확인표](teacher-guide.md)에 따라 진행합니다.
