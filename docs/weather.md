# 날씨와 습도

## 가져오기

1. 인터넷이 되는 [온라인 스튜디오](https://keyring-swart.vercel.app)의 **날씨**에서 지역을 고르고 **날씨 받기**를 누릅니다.
2. **파일 · 연습 → 파일 저장**으로 JSON을 받습니다.
3. 키링 Wi-Fi에 연결한 뒤 `http://192.168.4.1`의 **날씨 → 파일 · 연습 → 불러오기**에서 파일을 고릅니다.

검증된 파일은 연결된 ESP32 내부 NVS에 저장됩니다. 이후 인터넷 없이도 표시합니다. 키링 AP 자체에는 인터넷이 없으며, 휴대전화가 AP 연결 중 이동통신을 유지할 수 있을 때만 파일 이동 없이 직접 받을 수 있습니다.

## 간결한 화면

기본 화면에는 **웃는 날씨 아이콘 + 반올림한 온도 + 상대습도**가 나옵니다. 습도는 선택한 지역의 모델 기반 예보 값이며, 이 키트에 실내 습도 센서가 달려 있는 것은 아닙니다.

웹의 추가 정보는 필요한 항목을 펼쳐 봅니다.

| 메뉴 | 내용 |
| --- | --- |
| 24시간 예보 | 한 시간 간격의 온도·습도·아이콘 |
| 받은 시각 · 출처 | 마지막 업데이트, 현재 날씨의 기준 시각, 데이터 출처 |
| 파일 · 연습 | 파일 저장·불러오기, 연습용 날씨, 시각 맞추기 |
| 날씨 도움말 | 연결 방법, 시간·습도 설명, API 출처·라이선스 |

OLED도 같은 128×64 픽셀을 사용합니다. **날씨** 모드는 현재 날씨 8초와 시간별 예보 한 장 4초를 번갈아 보여 주며 다음 예보로 순서대로 넘어갑니다. **번갈아** 모드는 표정 12초 → 현재 날씨 8초 → 시간별 예보 한 장 4초입니다. 예보 화면에는 날짜·시각을 짧게 표시합니다. 24개 예보를 모두 확인하려면 웹의 **24시간 예보**를 펼치면 됩니다.

저장된 날씨가 최신 상태이면 기본 OLED에 설명 문장을 넣지 않습니다. 예외 상태만 작게 알립니다.

| 상태 | OLED 표시 | 의미 |
| --- | --- | --- |
| `missing` | 날씨 없음 | 저장된 날씨가 없음 |
| `sample` | 연습 날씨 | 실제 날씨가 아닌 연습 데이터 |
| `clock-unknown` | 시각 확인 | 재부팅 후 현재 시각을 아직 맞추지 않음 |
| `stale` | 지난 예보 | 받은 지 3시간 초과, 예보 범위 밖 또는 시각 불일치 |
| `fresh` | 별도 경고 없음 | 시간 동기화와 예보 유효 범위 확인됨 |

마지막으로 받은 시각은 웹의 **받은 시각 · 출처**에서 확인합니다. 실제 새 응답 없이 파일의 시각을 최신으로 바꾸지 않습니다. 연습용 데이터는 시간이 지나거나 시각을 맞춰도 실제 날씨로 바뀌지 않습니다.

## 실제 API와 이용 조건

[Open-Meteo Forecast API](https://open-meteo.com/)를 사용합니다. 키 없는 무료 API는 비상업적 사용 조건이 적용됩니다. 상업적 수업·제품에 사용한다면 [공식 이용약관](https://open-meteo.com/en/terms)을 확인합니다. 데이터는 [CC BY 4.0](https://open-meteo.com/en/licence)이며 웹의 날씨 도움말에 출처를 표시합니다. 모델 기반 자료이므로 현장 센서 실측과 다를 수 있습니다.

2026-10-23 확인한 [공식 약관 소스](https://github.com/open-meteo/open-meteo-website/blob/main/src/routes/en/terms/+page.svelte)는 비상업 무료, 하루 10,000회 미만·시간 5,000회·분 600회 제한과 무보증 조건을 명시합니다. 한 번의 버튼 조작에 한 번 요청하며 자동 재요청하지 않습니다. 사용 전에 최신 약관을 확인합니다.

| 요청 항목 | 용도 |
| --- | --- |
| `latitude`, `longitude` | 선택 지역 좌표 |
| `current=temperature_2m,relative_humidity_2m,weather_code` | 현재 기온·상대습도·WMO 코드 |
| `hourly=temperature_2m,relative_humidity_2m,weather_code` | 시간별 기온·상대습도·WMO 코드 |
| `forecast_days=2` | 다음 정시부터 24개 미래 시간 슬롯 확보 |
| `timeformat=unixtime`, `timezone=GMT` | UTC 초 단위 시각 |
| `temperature_unit=celsius` | 섭씨 |

예시 요청:

```text
https://api.open-meteo.com/v1/forecast?latitude=37.5665&longitude=126.9780&current=temperature_2m,relative_humidity_2m,weather_code&hourly=temperature_2m,relative_humidity_2m,weather_code&forecast_days=2&timeformat=unixtime&timezone=GMT&temperature_unit=celsius
```

수신 응답의 섭씨·퍼센트 단위, 배열 길이, 각 값을 검사합니다. 습도가 빠진 실제 API 응답을 임의의 값으로 채우지 않습니다. 2026-10-24 실제 API에서 현재·시간별 습도를 받아 다음 24개 예보로 변환한 것을 확인했습니다. 빌드·배포와 실물 확인 여부는 [버전별 실행 기록](verification.md)을 따릅니다.

## 시간과 재부팅

새 파일에는 다음 정시부터 24시간 예보를 담습니다. 예를 들어 14시 35분에 받으면 15시부터 다음 날 14시까지입니다. JSON은 UTC Unix 초로 저장하고 웹·OLED는 한국 시각(KST)을 표시합니다.

전원을 껐다 켜도 예보와 원래의 `fetchedAt`은 남습니다. 현재 하드웨어에는 배터리 백업 RTC가 없어 **재부팅 시 시계의 신뢰 상태는 해제**됩니다. 설정 화면을 열면 휴대전화 시각으로 동기화를 시도합니다. **파일 · 연습 → 시각 맞추기**로 다시 맞출 수도 있습니다. 휴대전화 시계가 틀리면 오차가 반영될 수 있습니다.

받은 지 3시간을 초과하거나 예보 범위를 벗어난 자료는 **지난 예보**로 표시합니다. 시각을 모르면 **시각 확인**을 표시하므로 저장 자료를 최신 실시간 자료로 오해하지 않게 합니다.

## 날씨 파일 형식

스키마는 기존과 같은 `1`입니다. 습도가 없는 이전 파일도 읽을 수 있으며 해당 습도는 **`--%`**로 표시합니다. 새로 받는 파일에는 현재·시간별 `humidity`를 포함합니다.

| 필드 | 자료형 | 설명 |
| --- | --- | --- |
| `schema` | 정수 | `1` |
| `source` | 문자열 | 실제 `open-meteo`, 연습용 `sample` |
| `location.name` | 문자열 | 지역 이름, 최대 96 UTF-8 바이트 |
| `location.latitude`, `location.longitude` | 숫자 | 위도 -90~90, 경도 -180~180 |
| `fetchedAt` | 정수 | API를 받은 시각, UTC Unix 초 |
| `current.time` | 정수 | 현재 날씨의 기준 시각 |
| `current.temperature` | 숫자 | 섭씨 -90~65, 유한한 값 |
| `current.code` | 정수 | 지원하는 WMO 코드 |
| `current.humidity` | 정수, 생략 가능 | 상대습도 0~100%; 생략은 이전 파일의 미제공 값 |
| `hourly` | 배열 | 정확히 24개, 각 항목은 위와 같은 `time`, `temperature`, `code`, 선택적 `humidity` |

0%와 100%는 유효합니다. `null`, 문자열, 소수 습도, 범위 밖 값은 거부합니다. 24개 예보는 3,600초 간격이어야 합니다. 오류가 있는 파일은 기존 저장 자료를 대체하지 않습니다. `source`는 인증된 서명이 아니므로 수업에서는 스튜디오가 만든 파일이나 교사가 준비한 파일을 사용합니다.

## 연결이 안 될 때

- 인터넷을 확인한 뒤 온라인에서 파일을 먼저 받습니다. 표정 기능은 인터넷 없이 계속 사용할 수 있습니다.
- 연습이 필요하면 **파일 · 연습 → 연습용 날씨**를 직접 고릅니다. API 실패를 연습용 데이터로 숨기지 않습니다.
- 실제 OLED가 예전 화면이면 [펌웨어 2.2.0 업로드](hardware-and-upload.md)를 진행합니다. GPIO4·GPIO5 배선은 그대로 사용합니다.
