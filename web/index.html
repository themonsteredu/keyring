    날씨 도움말

    키링 Wi-Fi는 인터넷을 제공하지 않아요. 연결 전에 날씨를 받아 파일로 저장한 뒤, 키링에 연결해서 불러오세요.

    전원을 껐다 켜면 휴대폰 시각을 다시 맞춰 주세요. 오래된 예보는 새로 받아 주세요.

    습도는 우리 동네의 날씨 예보 값이에요. 키링이 실내 습도를 측정하지는 않아요.

    날씨: Open-Meteo · CC BY 4.0 · 비상업적 교육용 무료 API. 현재 날씨를 포함한 모델 기반 자료이며 관측값과 다를 수 있어요.

    도움말

    내 키링에 연결하기

    1. 키링에 USB 전원을 연결해요.
    2. 휴대폰 Wi-Fi에서 Keyring-으로 시작하는 내 키링을 골라요.
    3. 비밀번호 keyring123을 입력해요.
    4. 브라우저에서 192.168.4.1을 열어요.
