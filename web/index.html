    Wi-Fi에 연결했는데 날씨를 받을 수 없나요?

    키링의 Wi-Fi는 설정용이라 인터넷을 제공하지 않아요. 휴대폰이 모바일 데이터를 함께 사용하지 못하면 다음 순서로 해 보세요.

    1. 인터넷이 되는 곳에서 이 웹 화면을 열고 실제 날씨 받기를 눌러요. 선생님이 제공하는 온라인 화면이나 컴퓨터의 개발 서버를 이용할 수 있어요.
    2. 날씨 파일 내려받기로 파일을 보관해요.
    3. 내 키링 Wi-Fi에 연결한 뒤 192.168.4.1을 열어요.
    4. 미리 받은 날씨 파일 불러오기로 파일을 골라요. 저장이 끝났다는 안내를 확인해요.

    휴대폰 날짜와 시간이 정확해야 해요. 전원을 완전히 껐다 켜면 키링의 시계가 초기화되므로 휴대폰 시각 맞추기를 눌러 주세요.

    실제 날씨: Open-Meteo · 비상업적 교육용 무료 API · CC BY 4.0 · 기상청 관측값이 아닌 모델 기반 자료이며 현재 날씨도 추정값이에요. 지역 좌표는 날씨 요청에만 사용해요.
